# Data card

The predictive evidence uses 149,639,105 labeled aggregate rows from the public KDD Cup 2012 Track 2 sponsored-search dataset: 235,582,879 impressions and 8,217,633 clicks. The source archive is not redistributed. Streaming validation found zero malformed rows in the canonical profile, and no exact setting group crossed data roles.

Product-treatment outcomes are a separate 16,977,840-session controlled semi-synthetic experiment. They are neither merged row-wise with KDD outcomes nor described as live traffic. Public evidence contains only aggregate results.
